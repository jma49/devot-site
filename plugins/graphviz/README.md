# Graphviz

A Devot plugin, listed at https://devot.online/docs/plugins. It needs Devot 1.1.8 or later.

A fenced code block marked `dot` shows as a Graphviz diagram in the preview, drawn in the text and line colours of the theme on screen; the note keeps the block as written.
A graph Graphviz cannot read shows its message instead.

It carries Graphviz itself, built for the web by Viz.js 3.31.0 (MIT licence; Graphviz under the Eclipse Public License, Expat under the MIT licence), and needs no network.
It asks for one permission, `preview`, and reads no note and changes none.
