# One Dark and Light

The cool grays and soft syntax colors of One: One Light for Light Mode, One Dark for Dark Mode.

Themes: One Light (Light Mode), One Dark (Dark Mode).
Choose one in Settings > Appearance, for Light Mode or for Dark Mode.

Every color of Devot is drawn from the One Dark palette by GitHub Inc. (https://github.com/atom/atom/tree/master/packages/one-dark-syntax), under the MIT License in `LICENSE`.
The theme files are generated by `pnpm plugin-themes` from `scripts/plugin-themes/palettes.ts`.

Needs Devot 1.1.8 or later.
