# Nord

Calm arctic blues and frosted grays, for Dark Mode.

Themes: Nord (Dark Mode).
Choose one in Settings > Appearance, for Light Mode or for Dark Mode.

Every color of Devot is drawn from the Nord palette by Sven Greb (https://github.com/nordtheme/nord), under the MIT License in `LICENSE`.
The theme files are generated by `pnpm plugin-themes` from `scripts/plugin-themes/palettes.ts`.

Needs Devot 1.1.8 or later.
