# Gruvbox

Warm retro browns, yellows and greens, for Light Mode and Dark Mode.

Themes: Gruvbox Light (Light Mode), Gruvbox Dark (Dark Mode).
Choose one in Settings > Appearance, for Light Mode or for Dark Mode.

Every color of Devot is drawn from the Gruvbox palette by Pavel Pertsev (https://github.com/morhetz/gruvbox), under the MIT License in `LICENSE`.
The theme files are generated by `pnpm plugin-themes` from `scripts/plugin-themes/palettes.ts`.

Needs Devot 1.1.8 or later.
