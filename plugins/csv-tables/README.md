# CSV Tables

A Devot plugin, listed at https://devot.online/docs/plugins.

- File > Import > CSV or TSV Table turns each `.csv` or `.tsv` file into a note holding one Markdown table, its first row as the header.
- A fenced code block marked `csv` shows as a table in the preview (the first 500 rows); the note keeps the block as written.

It asks for two permissions, `import` and `preview`, and reads no note and changes none.
