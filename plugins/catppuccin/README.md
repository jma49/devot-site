# Catppuccin

Soothing pastel colors: Latte for Light Mode; Frappé, Macchiato and Mocha for Dark Mode.

Themes: Catppuccin Latte (Light Mode), Catppuccin Frappé (Dark Mode), Catppuccin Macchiato (Dark Mode), Catppuccin Mocha (Dark Mode).
Choose one in Settings > Appearance, for Light Mode or for Dark Mode.

Every color of Devot is drawn from the Catppuccin palette by Catppuccin (https://github.com/catppuccin/catppuccin), under the MIT License in `LICENSE`.
The theme files are generated by `pnpm plugin-themes` from `scripts/plugin-themes/palettes.ts`.

Needs Devot 1.1.8 or later.
